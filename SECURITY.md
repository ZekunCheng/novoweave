# Security and responsible use

## Supported versions

This repository is a conceptual blueprint and has no supported production
release. Security fixes target the default branch.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature. Do not disclose secrets,
sensitive sequence data, personal data, or actionable misuse details in a
public issue.

## Biological scope

This project does not establish that any candidate is safe, functional,
non-toxic, non-pathogenic, manufacturable, or suitable for release. A future
implementation should include independent expert review, sequence screening,
access controls, provenance, audit logs, and explicit human authorization
before any downstream laboratory activity.

The maintainers do not support work intended to increase pathogenicity,
toxicity, immune evasion, host range, environmental persistence, or other
harmful biological properties.
