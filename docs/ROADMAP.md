# Roadmap

This roadmap is hypothetical and does not promise implementation dates.

## Phase 0 — contracts (current)

- Typed design brief, configuration schema, and component protocols.
- Explicit non-functional boundaries and responsible-use documentation.
- CI, contract tests, issue templates, and contribution policy.

## Phase 1 — data and provenance

- Dataset cards and license audit.
- Immutable preprocessing manifests.
- Leakage-resistant split definitions and regression fixtures.

## Phase 2 — reference adapters

- Small, inspectable baseline components.
- Deterministic checkpoint loading and versioned model cards.
- Resource estimates and numerical-stability tests.

## Phase 3 — evaluation

- Predeclared benchmark suite and baseline comparisons.
- Calibration, uncertainty, diversity, and failure-mode analysis.
- Independent review of scientific and responsible-use claims.

## Phase 4 — research release

- Reproducible artifacts and signed releases.
- Access, provenance, screening, and audit controls proportional to capability.
- Clear separation between computational hypotheses and experimental evidence.
